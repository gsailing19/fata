# fata 项目现状

> 最后更新：2026-08-07

## 是什么

fata 是一个“零服务器”的陌生人文字匹配工具。用户打开 fata.uk 写一段文字，浏览器先做安全和信号密度检查，Cloudflare Worker 生成 BGE-M3 嵌入、加密存入匹配池，找到情绪频率相近的陌生人后，双方通过各自邮箱通信。产品本身不保存聊天内容。

## 当前状态

- 域名 fata.uk 已上线，Cloudflare Pages + Worker + KV 已部署。
- 中英双语界面，单页 `index.html` + 浏览器模块。
- 2026-08-07：醒着原因标签与 3 小时时区窗口已接入匹配特征；Worker 通知邮件改为 2 a.m. 信笺；移除 `_kv<=3` 兼容读取与旧代理拦截；`findMatchInPool` 纯逻辑已抽取并单测；beacon 增加兜底；Worker 版本 `0083d0e4-26c5-46f1-881d-6140132e359b`。
- 匹配池：93 条 seed、8 条 matched、0 条真实用户 pending（2026-08-02 审计）。
- 流量：2026-08-01 约 73 PV / 38 UV，处于冷启动阶段。
- 本地验证：invariant 70/70；中文算法 F1 94.1%，英文 F1 84.2%；E2E 15/15。

## 产品定位

- 目标用户（v1 已确认）：深夜醒着的海外英文用户，包括失眠者、夜班/轮班族、独居青年、时差与远距离人群、夜间创作者；详见 `codex/AUDIENCE.md`。
- 媒介：邮件，不建聊天室。
- 节奏：异步优先，等待被设计成期待。
- AI 定位：AI 只做匹配和一次性的共振描述，然后退场。
- 隐私主张：架构即隐私，静态前端 + 加密池，无聊天数据库。
- 定位口径：`connection / letter app`，不叫 dating；陪伴/朋友优先，浪漫由双方自然发展。

## 硬约束

- 不注册公司、不备案、不建服务器。
- fata.uk 已注册；所有生产依赖使用 PaaS/SaaS（Cloudflare、GitHub、Resend、SiliconFlow）。
- 海外优先分发，国内不主动运营。

## 当前最重要的判断

P0 和 P1 已于 2026-08-03 完成，P2 基础设施已开始：本地验证脚本、CI、首次回测基线、冷启动清单和成本台账已建立。剩余 P2 依赖真实用户和运营数据。
